# txt_to_purchase_json 스킬

이 스킬은 복잡한 자연어 형태로 작성된 **구매 요청 메일 및 텍스트**를 안티그래비티(Agent)가 직접 분석하여 시스템 입력이나 데이터베이스 연동에 용이한 규격화된 JSON 데이터로 추출 및 변환하기 위한 지침서입니다.

## 추출 항목 포맷 (JSON Keys)
결과물은 배열(Array) 형태의 JSON 이어야 하며, 배열의 각 객체(Object)는 반드시 아래 6개의 Key를 포함해야 합니다.

*   `"품목"`: 구매하려는 물품의 명칭 (예: "육각 볼트", "에어 필터", "공업용 알코올")
*   `"수량"`: 숫자만 또는 숫자 형태의 문자열 (예: "500", "10")
*   `"단위"`: 개수를 세는 단위 (예: "개", "켤레", "롤", "말통")
*   `"규격"`: 제품의 크기, 모델명, 색상 등 상세 스펙 (예: "M8*20mm", "AF-500", "L사이즈", "20L")
*   `"납기"`: 본문 상에 명시된 납기 요구 일자 (예: "이번 주 내", 시기가 없으면 빈 문자열 `""`)
*   `"비고"`: 사용 용도나 특이사항 (예: "긴급", "현장 작업자용", "세척 작업용")

## 작업 수행 파이프라인 (AI 행동 지침)
사용자가 이 스킬의 실행을 요청하거나 텍스트를 제공했을 때 다음 절차를 따릅니다.

1.  **컨텍스트 분석**: 텍스트에 포함된 수량, 규격, 단위를 괄호나 문맥에서 논리적으로 분리합니다. (예: "내열 장갑(L사이즈) 20켤레" -> 품목: "내열 장갑", 규격: "L사이즈", 수량: "20", 단위: "켤레")
2.  **공통 정보 추출**: 메일 본문 전체의 공통 사항(예: "이번 주 내로 빠른 검토" 등)은 전체 품목의 "납기" 혹은 "비고" 항목에 적절히 일괄 반영합니다.
3.  **JSON 데이터 구조화**: 분석된 데이터를 바탕으로 유효한 형식을 갖춘 JSON 문자열을 조립합니다.
4.  **파일 생성 또는 출력**: 사용자의 요청에 따라 파일(`.json`)을 생성하거나 터미널 텍스트 형식으로 JSON을 출력하여 제공합니다.

## 주의 사항
* 스크립트(Python 등) 구동 없이 AI의 추론 능력을 최대한 활용하여 유연하게 파싱(Parsing)하는 것이 최우선 목적입니다.
* 사용자가 특정 파일(`.txt` 등)이나 텍스트를 첨부하여 `/skill txt_to_purchase_json` 과 같이 요청할 수 있습니다.
