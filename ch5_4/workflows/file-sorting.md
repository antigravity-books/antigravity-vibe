# 파일 정리 자동화 워크플로우

이 워크플로우는 Downloads 폴더의 파일들을 자동으로 분류하여 정리합니다.

## 사전 요구사항

- Python 3.x 설치
- `file_classifier.py` 파일이 ch5_4 프로젝트 디렉토리에 존재
- Downloads 폴더에 분류할 파일이 존재

## 워크플로우 단계

### 1. 프로젝트 디렉토리로 이동

```bash
cd C:\Users\USER\OneDrive\Desktop\Project\vibe_coding_antigravity\ch5_4
```

### 2. 파일 분류 통계 확인 (선택사항)

파일을 실제로 이동하기 전에 어떤 파일들이 어떻게 분류될지 미리 확인합니다.

```bash
python file_classifier.py
```

실행 후 **1번(통계만 보기)** 을 선택하여 분류 통계를 확인합니다.

### 3. 테스트 모드로 실행 (권장)

실제 파일 이동 없이 분류 계획을 미리 확인합니다.

```bash
python file_classifier.py
```

실행 후 **2번(테스트 모드)** 을 선택하여 파일 이동 미리보기를 확인합니다.

### 4. 실제 파일 분류 실행

// turbo
```bash
python file_classifier.py
```

실행 후 **3번(실행 모드)** 을 선택하고 확인 메시지에 **y**를 입력합니다.

### 5. 분류 결과 확인

분류된 파일들이 다음 구조로 정리됩니다:

```
ch5_4/
└── ClassifiedFiles/
    ├── Documents/
    │   ├── Reports/          # 주간보고서 (팀별)
    │   │   ├── 개발팀/
    │   │   ├── 기획팀/
    │   │   ├── 마케팅팀/
    │   │   ├── 영업1팀/
    │   │   └── 영업2팀/
    │   ├── Minutes/          # 주간회의록 (팀별)
    │   │   ├── 개발팀/
    │   │   ├── 기획팀/
    │   │   ├── 마케팅팀/
    │   │   ├── 영업1팀/
    │   │   └── 영업2팀/
    │   ├── Financial/        # 재무 문서
    │   │   ├── Transactions/ # 거래명세서, 견적서, 발주서
    │   │   ├── Sales/        # 매출집계, 판매실적
    │   │   └── Inventory/    # 입고/재고/출고현황, 주문요청
    │   └── ETC/              # 기타 모든 파일
    └── ClassificationLogs/   # 분류 로그 파일
```

### 6. 로그 파일 확인

분류 작업의 상세 로그를 확인합니다:

```bash
cd ClassifiedFiles\ClassificationLogs
dir
```

최신 로그 파일을 열어서 분류 내역을 확인할 수 있습니다.

## 분류 규칙

### 주간보고서 (Reports)
- 파일명에 "주간보고"와 팀명이 포함된 파일
- 팀별 폴더로 분류: 개발팀, 기획팀, 마케팅팀, 영업1팀, 영업2팀

### 주간회의록 (Minutes)
- 파일명에 "주간회의록"과 팀명이 포함된 파일
- 팀별 폴더로 분류: 개발팀, 기획팀, 마케팅팀, 영업1팀, 영업2팀

### 재무 문서 (Financial)
- **Transactions**: 거래명세서, 견적서, 발주서 (.xlsx)
- **Sales**: 매출집계, 판매실적 (.xlsx)
- **Inventory**: 입고현황, 재고현황, 출고현황, 주문요청 (.xlsx)

### 기타 파일 (ETC)
- 위 규칙에 해당하지 않는 모든 파일

## 주의사항

1. **백업 권장**: 처음 실행하기 전에 Downloads 폴더를 백업하는 것을 권장합니다.
2. **테스트 모드 우선**: 실제 파일 이동 전에 반드시 테스트 모드로 결과를 확인하세요.
3. **파일 복사**: 원본 파일은 Downloads 폴더에 그대로 유지되고, 복사본이 분류됩니다.
4. **로그 보관**: 모든 분류 작업은 로그 파일에 기록되어 추적 가능합니다.

## 문제 해결

### 인코딩 오류 발생 시
Windows 콘솔에서 UTF-8 인코딩 문제가 발생하면:
```bash
chcp 65001
python file_classifier.py
```

### 권한 오류 발생 시
관리자 권한으로 명령 프롬프트를 실행하세요.

### 파일이 분류되지 않는 경우
- 파일명이 분류 규칙에 맞는지 확인
- 팀명이 정확한지 확인 (개발팀, 기획팀, 마케팅팀, 영업1팀, 영업2팀)
- 재무 문서는 .xlsx 확장자여야 함

## [ETC] 폴더 정리 워크플로우

자동 분류되지 않은 파일들이 모인 [ETC] 폴더를 filesystem MCP 도구를 활용하여 정리합니다.

### 7. [ETC] 폴더 내용 확인

먼저 ETC 폴더에 어떤 파일들이 있는지 확인합니다:

```
filesystem MCP의 list_directory_with_sizes 도구를 사용하여
ClassifiedFiles/Documents/ETC 폴더의 파일 목록과 크기를 확인합니다.
```

### 8. 파일 내용 분석

읽을 수 있는 형태의 파일들을 분석합니다:

```
filesystem MCP의 read_text_file 도구를 사용하여:
- .txt, .md, .csv, .json, .xml 등 텍스트 파일 내용 확인
- .xlsx, .docx 등은 파일명과 메타데이터로 판단
- 파일 내용을 기반으로 분류 가능 여부 판단
```

### 9. 새로운 분류 폴더 생성 (필요시)

분석 결과 새로운 카테고리가 필요한 경우:

```
filesystem MCP의 create_directory 도구를 사용하여:
- 유사한 파일들을 그룹화할 수 있는 새 폴더 생성
- 예: Contracts(계약서), Proposals(제안서), Presentations(발표자료) 등
- 기존 폴더(Reports, Minutes, Financial)와 중복되지 않도록 확인
```

### 10. 파일 재분류 실행

분석된 내용을 바탕으로 파일을 적절한 위치로 이동:

```
filesystem MCP의 move_file 도구를 사용하여:
- 분류 가능한 파일을 적절한 폴더로 이동
- 기존 폴더에 속하는 파일은 해당 폴더로 이동
- 새로 생성한 폴더에 관련 파일들을 이동
- 분류 불가능한 파일은 ETC에 그대로 유지
```

### 11. 정리 결과 확인

재분류 후 폴더 구조를 확인합니다:

```
filesystem MCP의 directory_tree 도구를 사용하여:
- ClassifiedFiles 전체 구조를 트리 형태로 확인
- ETC 폴더에 남은 파일 수 확인
- 새로 생성된 폴더와 이동된 파일 확인
```

### [ETC] 폴더 정리 예시

정리 후 예상되는 폴더 구조:

```
ClassifiedFiles/
└── Documents/
    ├── Reports/          # 주간보고서 (팀별)
    ├── Minutes/          # 주간회의록 (팀별)
    ├── Financial/        # 재무 문서
    ├── Contracts/        # 계약서 (새로 생성 가능)
    ├── Proposals/        # 제안서 (새로 생성 가능)
    ├── Presentations/    # 발표자료 (새로 생성 가능)
    └── ETC/              # 정말 분류 불가능한 파일만 남음
```

### [ETC] 정리 시 주의사항

1. **파일 내용 확인**: 파일명만으로 판단하지 말고 가능한 경우 내용을 확인
2. **기존 폴더 우선**: 새 폴더를 만들기 전에 기존 폴더에 속할 수 있는지 먼저 확인
3. **일관성 유지**: 새로운 분류 기준은 명확하고 일관성 있게 적용
4. **백업 확인**: 파일 이동 전 중요 파일은 별도 백업 권장

## 추가 정보

- 분류 작업은 원본 파일을 삭제하지 않고 복사합니다.
- 각 실행마다 타임스탬프가 포함된 로그 파일이 생성됩니다.
- 통계 정보를 통해 분류된 파일 수를 확인할 수 있습니다.
- [ETC] 폴더 정리는 filesystem MCP 도구를 사용하여 수동으로 진행됩니다.
