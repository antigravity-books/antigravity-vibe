## 🛠️ 3. 설치 및 실습 시작 가이드 (Quick Start)

### 실습 자료 다운로드 (아래 방법 중 택일)

* **방법 A: ZIP 파일로 다운로드 (초보자 권장)**
  1. 본 GitHub 저장소 우측 상단의 **`🟢 Code`** 녹색 버튼을 클릭합니다.
  2. **`Download ZIP`**을 선택하여 내려받은 후, 원하는 폴더에 압축을 해제합니다.
* **방법 B: Git Clone 명령어 사용**
  실습 폴더에서 터미널을 열고 아래 명령어를 입력합니다.
  ```bash
  git clone https://github.com/antigravity-books/antigravity-vibe.git
  cd antigravity-vibe
  ```
