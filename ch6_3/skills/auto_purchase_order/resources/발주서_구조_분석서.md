# 구매발주서 엑셀 양식 분석서

본 문서는 `발주서 엑셀양식.xlsx` 파일의 셀 구조 및 병합 정보를 분석한 문서입니다. 구매발주서 작성 자동화를 위한 데이터 입력(Mapping) 기준표로 활용될 수 있습니다.

## 1. 타이틀 (Title)
- **셀 위치:** `A1:AB2` (병합됨)
- **기본값:** 구 매 발 주 서
- **설명:** 문서의 제목

## 2. 발주처 정보 (왼쪽 영역)
본사(발주를 하는 주체)의 정보를 입력하는 영역입니다.

| 항목명 | 라벨 셀 | 데이터 입력 셀(병합범위) | 설명 |
| :--- | :--- | :--- | :--- |
| 사업자 등록번호 | `B4` (B4:C4) | **`D3:N4`** | 발주처의 사업자 등록번호 |
| 상호 | `B5` (B5:C5) | **`D5:H5`** | 발주처 회사명 |
| 성명 | `I5` | **`J5:L5`** | 발주처 담당자 또는 대표자 성명 |
| 서명/인 | `M5` (M5:N5) | - | '(인)' 이라고 기재된 곳으로 서명 이미지 등이 들어갈 수 있음 |
| 사업장소재지 | `B6` (B6:C6) | **`D6:N6`** | 발주처 주소 |
| 업태 | `B7` (B7:C7) | **`D7:G7`** | 발주처 업태 |
| 종목 | `H7` | **`I7:N7`** | 발주처 종목 |
| 연락처 | `B8` (B8:C8) | **`D8:N8`** | 발주처 전화번호 등 연락처 |

> ※ 좌측의 `A3:A8`은 "발 주 처"라는 텍스트로 병합되어 있습니다.

## 3. 수주처 정보 (오른쪽 영역, 공급업체)
협력업체(발주를 받는 주체)의 정보를 입력하는 영역입니다.

| 항목명 | 라벨 셀 | 데이터 입력 셀(병합범위) | 설명 |
| :--- | :--- | :--- | :--- |
| 사업자 등록번호 | `P4` (P4:Q4) | **`R3:AB4`** | 수주처의 사업자 등록번호 |
| 상호 | `P5` (P5:Q5) | **`R5:V5`** | 수주처 회사명 |
| 담당 | `W5` | **`X5:Z5`** | 수주처 담당자 이름 |
| 사업장소재지 | `P6` (P6:Q6) | **`R6:AB6`** | 수주처 주소 |
| 업태 | `P7` (P7:Q7) | **`R7:U7`** | 수주처 업태 |
| 종목 | `V7` | **`W7:AB7`** | 수주처 종목 |
| 연락처 | `P8` (P8:Q8) | **`R8:AB8`** | 수주처 전화번호 등 연락처 |

> ※ `AA5:AB5`는 "귀하" 텍스트, `O3:O8` 영역은 "수 주 처" 텍스트로 병합되어 있습니다.

## 4. 발주 품목 입력 영역 (테이블 데이터)
발주할 품목의 목록이 들어가는 데이터 테이블 영역입니다. `10행`은 헤더이며, 실제 품목 데이터는 `11행`부터 `26행`까지 한 줄씩 입력할 수 있습니다. 각 열은 아래 셀 범위로 병합되어 있습니다.

**※ 데이터 행(Row) 범위: 11 ~ 26**

| 컬럼 헤더명 | 헤더 셀 (병합범위) | 데이터 열(Column) 병합범위 | 비고 |
| :--- | :--- | :--- | :--- |
| 순번 | `A10` (A10:B10) | **`A 열 : B 열`** | 예) 11행의 경우 `A11:B11` |
| 품명/규격 | `C10` (C10:G10) | **`C 열 : G 열`** | 예) 11행의 경우 `C11:G11` |
| 단위 | `H10` (H10:J10) | **`H 열 : J 열`** | 예) 11행의 경우 `H11:J11` |
| 수량 | `K10` (K10:M10) | **`K 열 : M 열`** | 예) 11행의 경우 `K11:M11` |
| 희망납품일자 | `N10` (N10:Q10) | **`N 열 : Q 열`** | 예) 11행의 경우 `N11:Q11` |
| 비고 | `R10` (R10:AB10) | **`R 열 : AB 열`** | 예) 11행의 경우 `R11:AB11` |

*(예시: 1번째 발주 품목을 삽입하려면 A11에 '1', C11에 품명, K11에 수량을 기입하면 됩니다. 병합된 셀의 경우 가장 좌상단 셀에 값을 입력합니다.)*

## 5. 하단 결재/발주서 발행 정보
- **문서 발행 일자:** `V28` 
  - 기본값 예시: "일자 : 2026년 4월 4일"
  - 데이터 자동화 시 이 셀에 기입된 날짜 형식을 변경하여 당일 날짜를 씁니다.
- **발주 회사 서명/이름:** `V29`
  - 기본값 예시: "㈜ 안티그래비티"
