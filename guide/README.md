## 🔍 가이드 북 주요 포함 내용 (미리보기)

책의 실습을 완벽하게 마스터할 수 있도록, 가이드북 안에는 아래의 핵심 내용들이 **생생한 화면 캡처 이미지와 함께** 들어있습니다!

> [!IMPORTANT]
> ### ⚙️ 1. Antigravity 2.x 최신 버전 설치법
> * **핵심 요약:** 에디터(IDE Mode)와 에이전트(Agent Mode)가 개별 프로그램으로 분리되었습니다.
> * **상세 내용:** 두 프로그램을 연동 충돌 없이 순서대로 올바르게 설치하는 방법을 스크린샷과 함께 안내합니다.

> [!NOTE]
> ### 🚨 2. 플랜 모드(Planning Mode) 스위치 소멸 대응
> * **핵심 요약:** 실물 책 **42~43p**에 나오는 수동 Planning 스위치가 완전히 사라졌습니다!
> * **상세 내용:** AI가 지시어 복잡도를 스스로 분석하여 계획서(`implementation_plan.md`)를 짜는 똑똑한 자동화 원리를 명쾌하게 해설합니다.

> [!TIP]
> ### 🙋‍♂️ 3. AI가 던지는 객관식 의사결정 UI 제어법
> * **핵심 요약:** AI 에이전트가 독단적으로 판단하지 않고 사용자에게 의사결정을 묻습니다.
> * **상세 내용:** 화면에 등장하는 다지선다형 질문창에서 원하는 방향을 선택하고 피드백을 전달하는 방법을 보여줍니다.

> [!WARNING]
> ### 💡 4. AI 시대, 왜 여전히 IDE 에디터가 필요할까요?
> * **핵심 요약:** 코드를 한 줄도 손대지 않는 자동화 시대에도 코드를 눈으로 직접 봐야 하는 이유입니다.
> * **상세 내용:** AI 비서를 완벽하게 지배하고 꼬인 문제를 스스로 해결하는 '진정한 개발 기초 체력'을 다져드립니다.
